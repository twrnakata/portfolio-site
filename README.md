# Tawanrung Nakata

Personal portfolio site for a senior software engineer working on Go backends, CRM, and loyalty platforms.

The site is a single static page: English by default, with an in-page Thai translation. It is hosted on Cloudflare Pages from this repository.

Related project: [loyalty-wallet-api](https://github.com/twrnakata/loyalty-wallet-api)

## Contents

| File | Role |
|------|------|
| `index.html` | Page structure |
| `styles.css` | Layout and light theme |
| `i18n.js` | EN / TH copy and language switch |
| `assets/cv.pdf` | Downloadable CV |

## Preview locally

Serve the repository root (any static file server):

```bash
python -m http.server 8080
```

Then open http://localhost:8080
